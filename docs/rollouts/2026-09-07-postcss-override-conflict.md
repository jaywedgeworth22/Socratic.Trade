# 2026-09-07 — Remove redundant postcss override (recurring Dependabot failure)

## Context & Objective

Every Dependabot Updates job touching `postcss` has failed since 2026-08-24 (recurred 08-24 x3, 08-25, 08-31, 09-07) with:

```
| postcss | dependency_file_not_resolvable | "Override for postcss@8.5.28 conflicts with direct dependency." |
```

Root cause: `package.json` pinned `postcss` identically in both the direct devDependency (`^8.5.15`) and the `overrides` block (`^8.5.15`).  Dependabot cannot bump one side of that pair without the other going stale, and flags the manifest as unresolvable rather than guessing which side to change.  Goal: stop the recurring failure without accidentally breaking a version pin something else depends on.

## Changes Made

- `package.json` — removed the redundant `"postcss": "^8.5.15"` entry from `overrides` (kept `overrides.axios` untouched).
- `package-lock.json` — regenerated by `npm install` to reflect the new resolution.

## Decisions & Trade-offs

Checked whether the override was load-bearing before removing it — i.e. whether any transitive dependency pins an *older* postcss that the override was forcing upward:

- `@tailwindcss/postcss@4.3.3` declares `postcss: ^8.5.16` — newer than the override's `8.5.15`.
- `vite` (vitest's dependency) declares `postcss: ^8.5.16` — same, newer.
- `next@16.3.4` declares `postcss: 8.5.23` (exact) and always resolves it in its own nested `node_modules/next/node_modules/postcss`, independent of the top-level override.

So the override was never forcing anyone to a version they didn't already want — it was doing nothing except duplicating the direct devDependency and giving Dependabot a resolvability conflict to report.  Removed it outright rather than keeping the two pins in lockstep, since there is no compatibility reason to keep postcss pinned as low as 8.5.15: nothing in the tree requires it, and letting npm's normal resolution pick the newest version satisfying all declared ranges (`^8.5.15` direct, `^8.5.16` from Tailwind/vite) is the simpler, more correct state.  No edge cases were deliberately left unaddressed.
